# HarperFast Brew

## How do I install these formulae?

`brew install harperfast/brew/<formula>`

Or `brew tap harperfast/brew` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "harperfast/brew"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
